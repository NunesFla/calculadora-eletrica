# ⚡ Calculadora de Ampere

Uma ferramenta web prática e rápida desenvolvida para auxiliar eletricistas na elaboração de orçamentos e pessoas que precisam calcular a amperagem de uma instalação elétrica sem complicações.

Com apenas alguns cliques, a aplicação calcula o consumo em amperes e recomenda a bitola ideal do cabo para a instalação, otimizando o tempo de profissionais com agendas cheias.

🔗 **Acesse a aplicação aqui:** [Seu-Usuario].github.io/[Nome-do-Repositorio]

---

## ✨ Funcionalidades

* **Cálculo Automatizado:** Insira a quantidade de dispositivos, a potência e a tensão para obter instantaneamente a amperagem consumida e a bitola do cabo necessária.
* **Compartilhamento Rápido:** Botão exclusivo para copiar o resultado formatado. Ideal para enviar diretamente ao cliente via WhatsApp ou e-mail, informando o que precisa ser comprado.
* **Suporte a PWA (Web App):** Pode ser instalado diretamente na tela inicial do seu celular (iOS/Android), tablet ou computador, funcionando como um aplicativo nativo e dispensando a necessidade de digitar o link sempre que precisar usar.

---

## 🚀 Como Usar

1. Acesse o link da aplicação.
2. Informe a **quantidade** de itens que serão instalados.
3. Insira a **potência** total dos equipamentos.
4. Selecione a **tensão** da rede elétrica (127V, 220V, etc.).
5. Visualize o resultado com a amperagem e a fiação recomendada.
6. Clique no botão de copiar para salvar o resumo e enviar para o seu cliente.

---

## 📲 Como Instalar na Tela Inicial (PWA)

### 🍏 No iOS (iPhone / iPad)
1. Abra o navegador **Safari** e acesse o site da calculadora.
2. Toque no botão **Compartilhar** (ícone de um quadrado com uma seta para cima).
3. Role a lista de opções e selecione **Adicionar à Tela de Início**.
4. Confirme tocando em **Adicionar** no canto superior direito.

### 🤖 No Android
1. Abra o navegador **Google Chrome** e acesse o site da calculadora.
2. Toque nos **três pontos** no canto superior direito.
3. Selecione **Adicionar à tela inicial** (ou *Instalar aplicativo*, se disponível).
4. Toque em **Adicionar** para confirmar.

## 💻 Como Rodar o Projeto Localmente

Como este projeto utiliza apenas tecnologias front-end nativas, você não precisa instalar nenhuma dependência pesada para executá-lo.

1. Clone este repositório para a sua máquina:
   ```bash
   git clone https://github.com/NunesFla/calculadora-eletrica.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd calculadora-eletrica
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador de preferência ou utilize a extensão **Live Server** do VS Code.
